By simply clicking buttons or activating options, the user can
view graphs that show, for example, how many cars have a certain
mileage, or whether cars with higher mileage tend to cost less.

For other developers:
Exploratory Data Analysis (EDA) application built with
Streamlit, which allows you to visualize distributions and relationships between
variables in a vehicle dataset (`vehicles_us.csv`).
It implements two interaction methods: buttons for quick visualization
and checkboxes for simultaneous comparative analysis.
